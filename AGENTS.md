## Общие правила

- Отвечай на русском.
- Если возникают спорные моменты при реализации или ты понимаешь, что тебе не хватает информации - лучше уточняй у меня, что и как сделать
- Придерживаемся принципов CleanArhitecture + Mobx 
- Маппинг из dto в entity производим внутри repository - в Bloc и UseCase приходит уже entity(если она есть)
- Маппинг из примитивов и entity(если они есть) в dto так же производим в repository. Сами мапперы храним в папке data/mappers, либо domain/mappers в зависимости от того, маппим мы dto в entity или одну entity в другую
- Методы для маппинга делаем в виде extensions с короткими названиеми toEntity/ toDto. Сам extension называем так название сущности + MapperExtension. Например для маппинга TripDto в TripEntity, будет TripDtoToTripEntityMapper
- Сами entity создаем на основе dto - копируем все поля и структуру из dto, а всю необходимую логику выносим в get-еры и другие методы в entity
- Старайся избегать вложенных if-ов, где это возможно. Если позволяет логика, придерживайся конструкции if(...) { return }, вместо if(...) {} else {}
- В слое presentation используем entity из domain
